# 🏦 Banking Customer Churn Analysis

A machine-learning and data analytics application that analyzes banking customer behavior, identifies churn patterns, predicts customer churn risk, and generates actionable customer-retention insights.

## 📌 Project Overview

Customer churn is a major challenge for financial institutions. This project analyzes customer demographics, account information, transaction behavior, and financial attributes to understand churn patterns and predict customers who may be at risk of leaving.

The project combines **data cleaning, exploratory data analysis, statistical analysis, SQL, and machine learning** in an interactive Flask application.

## 🎯 Key Objectives

* Analyze banking customer behavior
* Identify important churn drivers
* Perform customer segmentation
* Predict customer churn risk
* Evaluate machine-learning performance
* Generate actionable retention insights

## 🤖 Machine Learning

### Model

**Random Forest Classifier**

The model is used to classify customers based on their likelihood of churning.

### ML Workflow

```text
Raw Customer Data
        ↓
Data Cleaning
        ↓
Feature Engineering
        ↓
Categorical Encoding
        ↓
Train/Test Split
        ↓
Random Forest Model
        ↓
Churn Prediction
        ↓
Risk Analysis
```
